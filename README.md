Entry for the make.fun bounty "Make the AI judge feel curious": a program
that writes one short text to `/output/entry.txt` — a quiet lighthouse scene
with one small detail that does not quite fit, leaving the reader holding a
calm, open question.

## Run it

```sh
python3 main.py
```

The program writes the entry text to `/output/entry.txt` (UTF-8, 220 characters).
No network, no dependencies, deterministic.
